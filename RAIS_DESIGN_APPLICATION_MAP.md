# RAIS AGENCIES DESIGN APPLICATION MAP

This document maps every proven technique discovered in the Hercules reference website (`https://rais-agencies.onhercules.app/`) to our production RAIS Agencies B2B website.

---

## 1. Core Alignment & Non-Negotiable Boundaries

| Constraint | Reference Observation | RAIS Application Rule |
| :--- | :--- | :--- |
| **Pricing Policy** | Reference displays retail/consumer ₹ prices (e.g. ₹170, ₹355). | **Strict Zero-Pricing:** In accordance with wholesale B2B distributor rules, RAIS displays commercial pack sizes, HSN codes, and specifications. The price is replaced by **wholesale enquiry actions** (`+ Add to Quote` / `+ Add to Enquiry`). No monetary amounts appear anywhere on public pages or generated WhatsApp links. |
| **Brand Identity** | Reference uses RAIS Agencies logo with cyan wordmark. | **Official RAIS Identity:** Retain the official RAIS diamond monogram in gold, official wordmarks (`RAIS AGENCIES` and `FROZEN FOOD PRODUCTS`), and Rayachoty headquarters contact info (`9347453135` / `9573261696`). |
| **Product Catalogue** | Reference has a simplified subset of 43 items across 8 categories. | **Full 64 Verified SKUs:** Retain all 64 verified commercial SKUs across 8 categories, mapped cleanly into the new high-impact category panels. |
| **Food vs. 3D Packaging** | Reference uses 2D layered composite on 3D perspective plane. | **Hybrid Excellence:** Retain the 3D interactive WebGL inspector (which includes 3D momo, 3D nugget, 3D fries, and 3D corrugated carton), while adopting the reference's high-impact 3D perspective food hero stage and cryogenic category plinths. |
